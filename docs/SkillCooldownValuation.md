# Skill Cooldown Valuation

스킬 모듈의 버프와 디버프를 공통 가치로 환산하여 권장 쿨다운을 계산하는 기준표다.

이 문서의 숫자는 밸런스 기준이며 런타임이 액션을 역추적하는 규칙이 아니다. JSON에는 검토가 끝난 최종 쿨다운 값만 저장한다.

## Status

- 단계: `Draft v1`
- 환산 단위: `Cooldown Value (CV)`
- 기본 환산: `1 CV = 권장 쿨다운 1초`
- 확정되지 않은 단가는 `TBD`로 둔다.

## Principles

- 일반 버프 Module에는 슬롯 기회비용을 적용하지 않는다.
- 자신에게 불이익을 주는 디버프 Module만 디버프 가치와 소모한 슬롯 기회비용을 모두 보상받는다.
- 글로벌 Module은 패시브로 작동하므로 스킬 쿨다운을 증감하지 않는다. 발동 제한이 필요할 때만 자체 모듈 쿨다운을 별도로 사용한다.
- 일반 쿨다운은 모듈의 전투 가치를 조립된 스킬 쿨다운에 반영한다.
- 모듈 쿨다운은 해당 모듈의 최소 재사용 간격이며 일반 쿨다운을 대체하지 않는다. 두 쿨다운은 필요하면 함께 사용한다.
- 자신에게 주는 디버프는 빌드로 회피할 수 있으므로 동일한 적 디버프보다 낮게 평가한다.
- 모듈이 직접 가진 효과만 평가한다.
- 다른 모듈과의 조합, 조립 후 타점 수, 외부 효과의 반복 발동은 평가하지 않는다.
- 발동 확률과 조건 난이도처럼 해당 모듈 안에서 완결되는 조건만 반영한다.
- 100% 둔화, 완전 행동 불가 등 임계점에 가까운 효과는 선형적으로 평가하지 않는다.
- 퍼센트 쿨다운 조정은 쿨다운 자체를 조작하는 특수 모듈에만 허용한다.
- 일반 모듈은 순가치를 고정 쿨다운 증감값으로 제공한다.

## Usage

- 모듈이 직접 가진 효과를 아래 단가표에서 찾는다.
- 효과의 실제 수치와 지속시간에 맞게 단가를 조정한다.
- 버프와 적 디버프는 더하고, 자기 페널티 보상은 뺀다.
- 계산된 값을 해당 모듈의 고정 쿨다운 증감값으로 사용한다.
- 특수 쿨다운 모듈만 별도의 퍼센트 배율을 사용한다.

## Damage Anchor

피해 단가는 다음 전투 수치를 기준으로 정한다. 실제 기본 능력치는 이후 이 기준에 맞게 조정한다.

| 기준 | 값 | 상태 |
| --- | ---: | --- |
| 플레이어 기준 체급 | 중형 | 확정 |
| 플레이어 기본 공격력 | 25 | 확정 |
| 중형 일반 적 체력 | 100 | 확정 |
| 공격력 100% 피해 | 25 | 확정 |
| 중형 일반 적 처치 타수 | 공격력 100% 피해 4회 | 확정 |
| 기준 피해 | 공격력 100% = 피해 25 = 최종 피해 증가 0% = 0 CV | 확정 |
| 중형 적 처치 피해 | 공격력 400% = 피해 100 = 최종 피해 증가 300% = 18.75 CV | 확정 |
| 최종 피해 증가 상한 | 최종 피해 증가 400% = 공격력 500% = 피해 125 = 25 CV | 확정 |

피해 계수와 최종 피해 증가는 서로 다른 효과다. 피해 계수 `100%`는 최종 피해 증가 `0%`와 같고, 피해 계수 `500%`는 최종 피해 증가 `400%`와 같다. 다른 모듈이나 조립된 피해량을 곱해 잠재 가치를 다시 계산하지 않는다.

기준 피해를 초과하는 피해 계수 증가 `10%`와 최종 피해 증가 `10%`는 각각 `0.625 CV`다. 피해 계수 `400%`는 실제 피해 `100`, 중형 일반 적 체력의 `100%`, `18.75 CV`에 해당한다.

소형과 대형은 각각 체력 `50`, `200`을 초기 가이드로만 둔다. 현재 단가 계산에는 중형 체급만 사용한다.

## Decisions

- `1 CV = 1초`를 초기 표시 단위로 사용한다.
- 퍼센트 쿨다운 조정은 특수 쿨다운 모듈에만 허용한다.
- 속성 룬은 효과별 CV와 별개로 스킬 쿨다운 `+2초`를 공통 비용으로 사용한다.
- 가치 계산은 저작 도구의 책임이며 런타임은 최종 값만 사용한다.
